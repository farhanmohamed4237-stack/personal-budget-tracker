# SpendWise – Personal Budget Tracker

## Project Description

SpendWise is a personal budget tracking website that helps users monitor their expenses, understand their spending habits, and manage their monthly budget.

The website includes a financial dashboard, expense entry form, spending categories, expense records, and budgeting tips.

## Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive layout
- JavaScript – Interactive expense tracking and budget calculations
- GitHub – Source code hosting and version control
- Netlify – Website hosting and automatic deployment

## Deployment Process

1. Created a public GitHub repository for the SpendWise project.
2. Uploaded the project files: `index.html`, `style.css`, and `script.js`.
3. Connected the GitHub repository to Netlify.
4. Deployed the website using the `main` branch.
5. Configured the Netlify project name and public access.
6. Tested the live website.
7. Updated the website footer through GitHub.
8. Confirmed that the changes appeared on the live website through automatic deployment.

## Challenges Encountered

- Learning how to connect GitHub with Netlify.
- Finding an available custom Netlify site name.
- Understanding how to edit and commit changes directly on GitHub.

## Lessons Learned

- How to publish a static website using Netlify.
- How to manage project files in GitHub.
- How automatic deployment works when changes are committed.
- The importance of testing a website after deployment.
